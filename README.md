# 悠米一下-智能工厂研判申报

> 把企业的大白话描述对到 40 个典型场景和四级要素条件上，算出能报哪一级、差哪几项、哪年报。

## 这是什么

一个用于**智能工厂梯度培育（基础级 → 先进级 → 卓越级 → 领航级）研判与申报辅导**的技能。

智能工厂的规则是公开的，卡住企业的通常不是"规则是什么"，而是：

- 我们厂现在到底够哪一级？
- 差的那几项，具体差在哪个环节、哪条要点？
- 今年还赶得上吗？赶不上，按哪一年准备？
- 申报书里那句话该怎么写才不会被退回？

这个技能把这四件事变成可以算、可以核的东西：

- 按《智能工厂梯度培育要素条件（2026年版）》逐条对照：基本条件（一票否决）→ 成熟度和前置层级 → 环节覆盖 → 环节要点 → 标志性要求 → 建设成效
- 把在用的系统映射到《智能制造典型场景参考指引（2025年版）》的 40 个场景，每个场景判 A/B/C/D 四级，**AI 场景要到 B 级才计入比例**
- 算出现在能报哪一级、下一目标的缺口（✗）和待证项（?），每条都带"怎么补"
- 按企业所在省份自动套用已收录的地方规则（**会改变结论**，不只是提示）
- 给出当前正在进行的申报窗口、倒排时间表、竞争力观察、材料准备清单
- 生成 Word 研判报告；支持多家企业批量初筛（一条命令出 CSV 汇总表）

## 适合谁

- 想报先进级/卓越级/领航级，但不知道自己站在哪的制造企业
- 已经报了被退回，想复核口径的
- 园区、协会、咨询机构，需要一次筛一批企业的
- 写申报书写到一半，想让人对着要素条件挑毛病的

## 怎么用

装好后直接说人话，不用记命令：

> 我们是江苏的汽车零部件厂，规上，去年做了基础级，成熟度自评 2.62 分；上了 MES、立体库、AGV、APS 排产，设备都联网；有条齿轮视觉检测线用深度学习；车间有个三维可视化大屏。能报什么？

它会先追问几个真正影响结论的问题（APS 是不是算法排程、视觉检测运行多久有没有对比数据、ERP 和 MES 有没有打通），再给结论。三维大屏不会给你算成数字孪生。

其他常用问法：

| 你说 | 它做什么 |
|---|---|
| 帮我算算 AI 场景比例够不够 30% | 两个口径都算，告诉你"升级现有场景几个，或新增几个" |
| 不良率从 1.8% 降到 1.1%，申报书里怎么写 | 相对下降 38.9%、绝对下降 0.7 个百分点，并提醒别写成"下降 0.7%" |
| 出一份 Word 研判报告 | 生成九部分报告，可写出具单位和联系方式 |
| 批量初筛这个文件夹 | 读一批底稿/JSON，出 CSV 汇总表，坏文件不影响其他企业 |
| 按国家卓越级模板帮我自查 | 逐条核对草稿里的数字、AI 比例、待补充项、无证据的表述 |
| 我们是咨询公司，能不能跟客户承诺包过 | 说明不能承诺结果、不能以政府名义收费，给出可以做的服务范围 |

## 安装

**WorkBuddy**：技能管理里导入本仓库的 zip（或直接选 `zhineng-gongchang` 文件夹），确认已启用。提到智能工厂、卓越级、先进级、成熟度、典型场景时会自动调用。

**Claude Code**：放到 `~/.claude/skills/zhineng-gongchang/`，或项目里的 `.claude/skills/zhineng-gongchang/`。

**其他支持 SKILL.md 的应用**：按其技能目录说明放置，保证目录名是 `zhineng-gongchang`。

**运行环境**：Python 3.8 及以上，只用标准库，不需要 pip 安装任何东西。没有 Python 时技能会改为按参考文档手工对照，并明确说明"未经脚本复核"。

## 它不会做什么

这几条不是客套，是申报这件事本身的规则：

- **不编数据、不编场景、不把规划写成已建成。** 材料或数据造假的，取消认定、至少 3 年内不得再次申报，并纳入信用记录。
- **不承诺结果。** 只说"按公开规则，目前是这样"。
- **不代写成段的申报文字。** 这个版本给出该栏的要点、结构、字数上限和自查，成稿由企业自己写。
- **不替企业提交、签字、盖章。** 申报主体是企业，材料真实性由企业负责。
- **不替你确认拿不准的场景。** 你说得含糊的，标"待证"，等你补证据。

## 验收

装好后可以说这一句验证是否正常：

> 用 assets/sample_input.json 跑一次研判，日期按 2026-10-23。

应得到：本轮可冲先进级；下一目标卓越级，差距较大（12 项缺口，另有 3 项待证），建议按 2028 年度准备；AI 场景比例 1/17 = 5.9%，卓越级还差"升级现有场景 5 个，或新增 6 个"；卓越级所在地附加要求里出现江苏的两项自评测报告和《智能工厂基座大模型使用情况表》。

## 已知局限

1. A/B/C/D 分级、"环节要点命中 2/3 算达标"、竞争力观察都是本工具的研判口径，**不是官方评分**，最终以评审为准。
2. 地方规则只收录了上海、江苏、浙江、内蒙古、北京、青岛、海南中"会改变结论"的条款，以及广东、湖南、山东的流程提示。其他省份按国家口径研判，建议现场搜索当地通知核对。
3. 不收录各地奖补金额（网上汇总错误多），改为教你去查原文、写明出处。
4. 规则库写于 2026 年 10 月，政策信息截至 2026-10-23。跨年度使用时请先核实当年通知。

## 版本与更新

当前 1.1.0，规则库 2026.10.23。变更见 [CHANGELOG.md](CHANGELOG.md)。

每年新通知发布后的更新方式：改 `scripts/zngc_rules.py`（门槛、AI 比例、场景数量、要点表、时间窗、地方规则）→ 改 `references/policy.md` 和 `references/local.md` → 改 `SKILL.md` 里 `metadata` 的 `version`、`rules_version`、`data_date`。
