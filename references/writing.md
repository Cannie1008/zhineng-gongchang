# 申报书写作与填报

所有结构和字数上限来自公开的2025年度国家平台操作说明和上海市2026年先进级申报书模板，属于“往年口径”。当年平台或地方模板与此不同的，以当年为准。

## 1. 国家平台：卓越级、领航级怎么填

平台：智能制造数据资源公共服务平台（www.miit-imps.com）。2025年度平台分八个部分：

| 部分 | 内容与上限 |
|---|---|
| 申报基本信息 | 企业信息；上传成熟度自评估（或其他能力证明）和制造业数字化转型通用评估结果，点选等级、填写得分；系统解决方案供应商类型；整体建设成效指标（可自定义增加） |
| 工厂建设总体情况 | 实施背景和基础条件≤1000字；集成贯通情况≤1500字；每栏图片≤5张、每张≤15MB |
| 重点环节智能化建设情况 | 工厂建设、研发设计、生产作业、生产管理、运营管理各≤1500字、图片≤5张；场景化建设方案：生产作业、生产管理、运营管理必填，工厂建设、研发设计选填；场景列表里不同场景名称≥8个 |
| 场景实例 | 按“大环节→小环节→场景”选择；填写场景实例描述；选择是否应用人工智能，选“是”则填写人工智能技术应用情况≤300字；关键装备、软件、工艺、技术情况选填 |
| 项目先进性与特色 | ≤1500字 |
| 项目的安全性 | ≤1500字：关键技术装备、工业软件、系统解决方案的安全可控；网络安全和数据安全 |
| 项目实施成效 | ≤2000字：创新、经济性、复制推广、标准研制、人才培养 |
| 后续实施计划 | 预期目标、下一步建设内容和实施计划、成长性分析、推广应用计划，各≤1000字 |
| 附件（选填） | 关键技术清单、关键装备清单、关键软件/系统清单、标准清单、专利清单、人工智能模型清单 |

提交：生成申报书 → 下载 → 首页和真实性及保密承诺页盖章 → 上传盖章件（≤100MB）→ 确认提交。提交后通常不能再改，地方截止前留出盖章流转时间。

2026年度依据换成了要素条件（2026年版），平台可能增加人工智能场景比例、智能体数量、词元调用量等字段。以登录平台看到的模板为准。

**2026年度材料（各地转发口径汇总）**
- 平台上传：营业执照、近三年财务审计报告、智能制造能力成熟度评估报告、基础能力证明（近三年奖项、专利、软件著作权等）、其他证明材料（深圳转发广东通知）。
- 工厂简介视频：不超过8分钟、200M，mp4、avi、mov、mkv、rmvb；主要展示场景建设特别是生产环节，可配音讲解。
- 江苏另加：省“制造业领域人工智能技术场景应用水平”“制造业数据治理能力”两项自评测报告，以及《智能工厂基座大模型使用情况表》，作为申报书附件。

**纸质件（按推荐单位要求，差异很大）**
- 国家层面：推荐单位报送盖章纸质申报书、推荐汇总表、推荐函各1份；企业的纸质申报书须与线上一致。
- 北京：一式两份邮寄市经信局。湖南：省级专家评审后提交2份。济南高新区：2份胶装，书脊标注地市、申报年份和企业名称，另交PDF和Word电子版。
- 线上提交后改不了，地方截止又早于国家，盖章、装订、快递至少留出3个工作日。

## 2. 省级先进级：以上海2026年模板为例

各省模板不同，上海的最细，适合作为写作底稿。

- **一、申报主体和智能工厂基本信息**：工厂名称以“智能工厂”结尾、不超过14个汉字；近三年资产总额、资产负债率、主营业务收入、纳税总额、利润率；员工情况；企业简介≤1500字；建设起止、总投资、项目简述≤1000字；成熟度自评估结果、分数和类型（自评、评估诊断报告或CMMM证书）；数字化转型通用评估（选填）；应用人工智能技术场景比例。
- **二、工厂建设背景**≤1500字：必要性、建设历程。
- **三、工厂建设内容**≤5000字：总体架构；重点环节和场景建设情况（附件1场景实例、附件2关键装备软件模型）；智慧供应链（选填）。
- **四、工厂建设成效**≤2000字：先进性与特色、关键指标改善（附件3）、应用推广、绿色安全、人才培养、相关附件。
- **五、后续实施计划**≤1500字。
- 格式：正文5000—10000字；仿宋GB2312三号，固定行距28磅；每个场景至少配一张图，图片不小于2MB、不低于800万像素。
- 附件1（每个场景实例一张表）：环节、场景、实例名称、是否应用人工智能、是否成效突出具有推广价值；场景实例描述、解决的痛点、解决方案、实施成效四栏各≤500字。
- 附件2：关键装备分七类（高档数控机床、工业机器人、增材制造装备、智能传感与控制装备、智能检测与装配装备、智能物流与仓储装备、行业成套装备）；关键软件分六类（研发设计、生产制造、经营管理、控制执行、行业专用、新型软件）；模型分三类（数据模型、机理模型、融合模型）。
- 附件3：关键指标建设前和当前值，带“必填”标记的见 kpi.md。

## 3. 场景实例怎么写

一个场景实例就是一个小案例。评审要在一分钟内看懂四件事：原来哪里痛、现在怎么做、数据和模型在里面干了什么、效果多少。

**场景实例描述**：在哪个车间或工序、对象是什么、覆盖多大范围（设备台数、产线条数、物料种类、人员）。
**痛点**：建设前怎么做，问题是什么，用一个数字说明代价（漏检率、换线时间、库存天数）。
**解决方案**：说清三条链。
- 数据链：采集点和系统（哪些设备、多少点位、多久刷新一次），数据流到哪些系统。
- 模型链：用了什么算法或模型，输入什么、输出什么、多久更新一次。
- 闭环链：结果怎么落地（自动执行、推送到哪个系统、谁来采纳、错了怎么纠正）。
装备和软件写清自研还是外购、品牌和来源，和“安全性”栏目互相呼应。
**实施成效**：2—3个指标，建设前→当前，写统计期和口径；数字要和关键指标表一致。
**配图**：现场照片和系统界面各一张，界面能看到实时数据和时间戳。

对比一下：
- 弱：“建设了视觉检测系统，实现了产品质量的智能检测，检测效率大幅提升。”
- 强：“在齿轮精加工后段6个工位部署视觉检测，相机采集齿面图像，深度学习模型识别磕碰、划伤等5类缺陷，判定结果实时写入质量系统并触发分拣；模型每月用复判样本更新一次。2025年对比2023年，漏检率由X%降至Y%，单件检测节拍由A秒降至B秒（质量系统统计，全年口径）。”

## 4. 人工智能场景怎么写

- 写清技术类型：统计机器学习、深度学习、机器视觉、强化学习、知识工程、生成式人工智能、工业智能体（参照上海2026年模板注释口径）。
- 写清AI在这个场景里干了什么，而不是“用了一个带AI的系统”。
- 模型要素：名称和版本、训练数据来源和规模、上线时间、调用频次、效果指标（准确率、召回率等）、人工复核机制。
- 大模型和智能体：部署方式（私有化或云服务）、接入了哪些系统、任务边界、是否闭环执行、调用日志、数据安全和伦理措施。
- 不要把规划写成在用；不要把纯运筹优化或规则引擎硬说成人工智能（是否计入以当年口径为准，拿不准就不计）。
- 每个AI场景都要能在模型清单里找到对应条目；申报书里的AI场景比例要和场景清单逐个对得上。

## 5. 其他栏目的写法要点

- **实施背景和基础条件**：企业概况（有依据的行业地位）→ 为什么建（行业痛点、企业战略）→ 建设历程（时间轴、分阶段投资）→ 基础条件（成熟度等级、已获评级别、团队、关键系统）。
- **集成贯通情况**：一张总体架构图，加一段数据流说明：设备层→控制层→执行层（MES、WMS、QMS）→经营层（ERP、PLM、SRM）→数据平台和决策层。写主数据怎么统一、多少个系统接口、数据多久同步一次。
- **先进性与特色**：挑三个特色，每个按“做法→和谁比→证据”写，证据是专利、软著、标准、奖项、第三方评价。
- **项目的安全性**：关键装备、软件、系统清单和自主可控情况；等保测评级别；工控安全措施；数据分类分级、备份和权限；应急预案。
- **项目实施成效**：经济性（引用指标表）、创新、复制推广（家数和合同）、标准（名称和状态）、人才（培训人次、认证人数）。
- **后续实施计划**：量化目标、建设内容和时间表、成长性（产能、营收预期）、推广计划。正在建的内容放这里，不要写进“已建成”。

## 6. 工厂简介视频

2026年度多地转发口径：不超过8分钟、不超过200M，常见格式mp4、avi、mov、mkv、rmvb；以场景建设尤其是生产环节为主，可配讲解。建议按申报书场景顺序拍，每个场景打字幕（场景名＋一个关键数据），画面里能看到系统在实时运行，不出现涉密内容。

## 7. 最常见的退回和扣分原因（经验总结）

1. 场景堆砌：一个系统拆成好几个场景；场景名称和内容对不上。
2. 只写系统名，不写数据从哪来、模型干了什么。
3. 成效数据口径不清，百分点和百分比混用，和指标表对不上。
4. “国际领先”“填补空白”等说法没有证据。
5. 在建内容写成已建成；视频、现场和文字对不上。
6. AI场景比例凑数：把规划中的、没有模型的也算进去。
7. 建设投资和合同发票对不上。
8. 写进了客户名称、单价、配方和工艺参数等商业秘密。
9. 字数超限被截断，图片不清楚。
10. 基础材料缺：成熟度报告、审计报告、盖章的真实性承诺。

## 8. 自查命令

```
python scripts/zngc.py check 草稿.txt --input-json 输入.json --template 国家卓越级
python scripts/zngc.py check 草稿.txt --input-json 输入.json --template 上海先进级
```

草稿用【栏目名】分节（如【实施背景和基础条件】），检查会统计各栏字数，找出需要证据的说法、和研判对不上的数字、没有对应场景的AI说法、待补充占位和可能涉密的词。
