# 现场核查与答辩准备（经验总结，不是官方清单）

卓越级有现场抽查，领航级另有答辩；不少省份的先进级也有专家现场评估（上海是材料审核、专家现场评估加答辩，江苏由区县按现场核查表核查）。2026年度国家通知还要求各地对拟推荐的卓越级、领航级项目加强现场抽查，所以省里推荐之前往往先看一次现场。现场的逻辑只有一句话：申报书里写的，现场都要能看到、能点开、能追到原始数据。

## 专家通常怎么看

1. 按申报书逐个场景走现场：看设备、看系统界面、看实时数据。
2. 随机抽查：任选一个批次正反向追溯；任选一个指标要原始台账；任选一个AI场景要模型清单和运行记录。
3. 看一致性：申报书、视频、现场三者一致；一线人员能讲清自己用的系统。
4. 看安全可控：关键软硬件清单、等保测评、工控安全措施。

## 准备清单

- 场景走线图：按申报书顺序排路线，每个场景配一名讲解人（优先一线负责人，不要全程由信息部门讲）。
- 每个场景的“30秒讲法”：原来的痛点 → 做了什么 → 数据从哪来 → 模型干了什么 → 效果多少。
- 指标台账：打印版加系统导出版，统计期和口径写在表头。
- AI材料：模型清单、训练数据说明、上线记录、准确率统计、人工复核记录；智能体运行日志、大模型调用日志（申报书里填了才需要，但填了就必须有）。
- 系统准备：账号、网络、投屏都提前试；演示用的是真实生产数据，不是测试环境。

## 常见追问

- 这个场景建设前怎么做？现在谁在用、每天用几次？
- 数据从哪个设备或系统来？多久刷新一次？有没有人工补录？
- 模型输入输出是什么？多久更新？准确率怎么统计？判错了怎么办？
- 这个指标的统计期和口径是什么？原始数据在哪？
- 总投资多少？哪些是自研？关键软件的来源和自主可控情况？
- 下一步做什么？这套做法能推广给谁、推广了几家？

## 领航级答辩

- 讲清“引领”：全球领先的证据（对标数据、国际客户、标准话语权）、母工厂或对外输出、解决方案对外服务的合同。
- 讲清“智能体”：任务边界、接入的系统、闭环方式、效果、安全和伦理风险控制。
- 一页一个结论，控制时间，数字和申报书完全一致。

## 红线

用测试环境冒充生产环境、临时补录数据、为了核查临时上线功能，一旦被发现会按造假处理：依据管理办法，已认定的取消，并且至少3年内不得再次申报。
